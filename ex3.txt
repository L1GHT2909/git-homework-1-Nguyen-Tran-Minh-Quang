PART D
1. 
mkdir permissions
cd permissions
touch secret.txt shared.txt public.txt
chmod 600 secret.txt
chmod 664 shared.txt
chmod 777 public.txt
2. 
umask
touch testfile.txt
ls -l testfile.txt

Explanation:
- Default file permission before umask is 666 (rw-rw-rw-).
- Current umask is 0022.
- The resulting permission is calculated as 666 - 022 = 644 (rw-r--r--).
- Therefore, the file testfile.txt has read and write permissions for the owner, and read-only permissions for the group and others.
